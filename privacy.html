Revizor Privacy Policy

Effective date: 23 November 2026

What the application is

Revizor is a private tool used by a single person, the owner of the Google account it connects to. It is not a public service and is not offered to other users.

What access it requests

The application requests only the Gmail scope https://www.googleapis.com/auth/gmail.readonly. It cannot send, delete, label or modify any email.

What data it reads

The application lists and reads only messages from one sender chosen by the owner. Other messages in the mailbox are not opened.

How data is stored and used

The application stores data only on devices controlled by the owner and does not transmit Gmail data to any third party. Derived information is used only by the owner's own tools. Data is not sold, not used for advertising, and not used to develop, improve or train generalized artificial intelligence or machine learning models.

Revizor's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions about this policy can be raised through GitHub Issues for this site.
